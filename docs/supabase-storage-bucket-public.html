Is my Supabase storage bucket public? How to check and fix it

Lovable, Bolt and Cursor often create a bucket for uploads and leave it public. A public bucket serves any file to anyone who has its URL, with no policy check.

1. List your buckets

select id, public from storage.buckets;

Every row with public = true serves its files to anyone. That is fine for avatars; it is not for invoices, uploads or exports.

2. Make private files private

Make those buckets private and use createSignedUrl() to give a signed-in user a short-lived link to their own file.

3. Check the rest of the database too

A private bucket doesn't protect your tables. Check Row Level Security with the same SQL editor:

select schemaname, tablename
from pg_tables
where schemaname = 'public' and rowsecurity = false;

Every row returned is a table that the anon key can read and write through the REST API. Full walkthrough: the Supabase RLS checklist.
